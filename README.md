# 女仆布娃娃

# 简介

一个可以把女仆变成布娃娃的模组。

**目前并不能完全支持全部模型，支持的模型可以在游戏内按下 F3+H 后在女仆的模型界面可以查看**

# 功能
## 1.女仆布娃娃态

![](image\3.gif)

女仆在某些情况下会进入布娃娃状态，此时可以被其他物理结构推动，破坏任意肢体后恢复实体状态。（肢体被破坏会删除整个布娃娃）

## 2.蛋糕盒

![](image\1.gif)

在蛋糕盒中的女仆如果支持布娃娃，将会以布娃娃形态抛向最近的玩家。

## 3.假死护符

![](image\2.gif)

在祭坛上由一个黄色染料和任意羊毛合成，女仆在装备后如果血量过低时受到攻击或死亡时饰品会将其变为布娃娃并取消受伤/死亡。

此状态下女仆会恢复血量，在血量达到 20 点时会恢复正常。
